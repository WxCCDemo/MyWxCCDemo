# Supabase Setup

Run [novapay-github-pages.sql](/Users/shailesh/DevProjects/MyWxCCDemo/NovaPay%20Service/supabase/novapay-github-pages.sql) in your Supabase SQL editor.

The script creates:

- `novapay_sessions`
- `create_novapay_session`
- `get_novapay_session`
- `complete_novapay_session`

The checkout page uses these RPC functions directly from GitHub Pages.
